# BlogNest

This is my first web project. I learned HTML and CSS and built this blogging website as a student project.

## Project Name
BlogNest

## About the Project
BlogNest is a simple blog website where users can:
- view blog articles
- open article pages
- create a new article
- register and login
- view a profile
- browse different pages in the website

This project helped me understand how web pages are built and connected together.

## Technologies Used
- HTML
- CSS
- JavaScript

## Pages in this Project
- Home page
- Articles page
- Create article page
- Login page
- Register page
- Profile page
- Individual article pages

## How to Run This Project
1. Download or clone this project.
2. Open the folder in VS Code.
3. Open `Index.html` in a browser.
4. You can also use a local server if needed.
